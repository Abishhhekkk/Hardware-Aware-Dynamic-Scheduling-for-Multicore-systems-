# Hardware-Aware Dynamic Scheduling for Multicore Linux Systems

## Overview
Developed a **hardware-aware adaptive scheduling framework** for multicore Linux systems focused on reducing shared hardware resource contention and improving execution predictability in embedded multicore environments. The framework dynamically profiles runtime workload behavior using Linux hardware performance counters through `perf_event_open()` to monitor **Instructions Per Cycle (IPC)**, cache miss rates, and processor utilization in real time.

---

## Core Features

- **Runtime IPC and Cache Miss Profiling**
  - Dynamically monitored workload execution behavior using Linux hardware performance counters.

- **Hardware-Aware Workload Classification**
  - Classified workloads as:
    - Compute-Intensive
    - Memory-Intensive
    - Mixed/Dynamic

- **Adaptive CPU Affinity Management**
  - Implemented intelligent core placement using `sched_setaffinity()`.

- **Dynamic Runtime Task Migration**
  - Migrated workloads across CPU cores based on runtime behavioral changes.

- **Load-Aware Scheduling**
  - Continuously balanced multicore utilization to reduce bottlenecks.

- **Migration Hysteresis Stabilization**
  - Prevented excessive scheduling oscillation using workload stability counters.

- **Userspace Linux Scheduling Framework**
  - Implemented entirely in userspace without requiring Linux kernel modifications.

---

## System Implementation

Implemented a lightweight userspace scheduling daemon on a **Raspberry Pi 3 multicore platform** capable of:

- Dynamic process discovery
- Runtime workload profiling
- CPU utilization monitoring
- Adaptive workload classification
- Load-aware balancing
- Stability-aware migration control
- Runtime reprofiling

The scheduler continuously analyzed runtime hardware behavior and dynamically optimized workload placement to reduce cache contention and improve execution locality.

---

## Experimental Evaluation

Built a synthetic workload benchmarking framework consisting of:

- Compute-intensive workloads
- Memory-intensive workloads
- Mixed workloads
- Dynamically shifting workloads

Experimental evaluation demonstrated:

- Accurate runtime workload classification
- Reduced cache contention
- Improved workload isolation
- Adaptive runtime migration
- Balanced multicore utilization
- Stable scheduling behavior
- ~52% higher system instruction throughput compared to Linux CFS
